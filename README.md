LC-Notepad is a fast, lightweight, and user-friendly web application designed for quick note-taking. Hosted seamlessly on GitHub Pages, it provides a distraction-free environment for users to jot down their thoughts, tasks, and daily notes instantly.

By leveraging browser's Local Storage, LC-Notepad automatically saves your text, ensuring that your data is securely stored on your device without the need for an internet connection, backend databases, or account registration.

🚀 Key Features:

Simple & Intuitive UI: A clean interface that helps you focus purely on your notes.
Auto-Save Functionality: Never lose your progress; everything is saved locally in real-time.
Fully Responsive: Works flawlessly across all devices (Desktop, Tablet, Mobile).
No Sign-up Required: Jump straight into writing securely and privately.
🛠️ Built With:

HTML5 / CSS3
Vanilla JavaScript (or React/Vue if you used them)
Deployed on GitHub Pages
